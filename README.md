## 🌟 هدف این مسیر / The Goal of This Journey

**فارسی**  
هدف از این مخزن، مستندسازی یک مسیر یادگیری ۶ ماهه برای تبدیل شدن به یک **مهندس Backend متخصص در هوش مصنوعی** است. من با ساختن ۶ پروژهٔ گام‌به‌گام، از مفاهیم پایهٔ Backend شروع کرده و به استقرار یک سیستم هوشمند و آمادهٔ تولید (Production-Ready) خواهم رسید.

**English**  
The goal of this repository is to document a 6-month learning journey to become an **AI Backend Engineer**. By building 6 step-by-step projects, I will start from core Backend concepts and progress to deploying a production-ready, intelligent system.

---

## 🎯 ۶ پروژه، ۶ هدف / 6 Projects, 6 Goals

**فارسی**  
هر ماه بر روی یک پروژهٔ عملی متمرکز خواهم بود که مهارت جدیدی را به چالش می‌کشد:

1. **ساخت API مدیریت کاربر** (FastAPI + JWT) - پایه‌ای برای امنیت و معماری  
2. **ربات تلگرام هوشمند** (OpenAI + Docker) - اولین تجربهٔ عملی با LLM  
3. **سیستم گفتگو با PDF** (RAG دستی) - درک عمیق از بازیابی اطلاعات  
4. **سیستم هوشمند اسناد** (RAG پیشرفته) - تسلط بر فریم‌ورک‌های تخصصی  
5. **عامل پژوهشگر خودکار** (Agent) - یادگیری ساخت سیستم‌های چندعاملی  
6. **دستیار کامل هوش مصنوعی** - تلفیق همهٔ مهارت‌ها و استقرار نهایی

**English**  
Each month is dedicated to a hands-on project that challenges a new skill:

1. **User Management API** (FastAPI + JWT) - Foundation for security and architecture  
2. **AI Telegram Bot** (OpenAI + Docker) - First practical experience with LLMs  
3. **Chat with PDF System** (Manual RAG) - Deep understanding of information retrieval  
4. **Document Intelligence System** (Advanced RAG) - Mastering specialized frameworks  
5. **Autonomous Research Agent** (Agent) - Learning multi-agent systems  
6. **Complete AI Copilot** - Combining all skills and final deployment
